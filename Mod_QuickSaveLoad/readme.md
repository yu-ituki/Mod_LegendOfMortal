# Mortal QuickSaveLoad Mod

『活俠傳 (Legend of Mortal)』向けのクイックセーブ＆クイックロード Mod です。

キー一つで手軽にセーブ＆ロードができるようになります。

---

## 🎮 機能

* **F5 キー**: クイックセーブ（専用スロット `quicksave` へ保存）
* **F9 キー**: クイックロード（`quicksave` スロットから読み込み）

---

## 🛡️ 安全設計（セーブガード仕様）

進行不可バグやセーブデータの破損を防ぐため、**安全性が確保されているタイミングでのみセーブが実行される**よう内部でガードを設けています。

* **セーブ可能なタイミング (F5)**
* マップ移動画面や拠点（唐門）での自由行動時など、安全に入力操作を行えるタイミング


* **セーブ不可のタイミング (F5を押しても弾かれます)**
* 会話・イベント演出中 (`Story`)
* タイトル画面 (`Title`)
* バトル中 (`Battle` / `Combat`)
* ゲームオーバー・エンディング画面
* 画面遷移中・ロード中 (`IsPrepare` / `IsLoading`)



> **※ ロード (F9) について**
> 会話中やタイトル画面、バトル中からでも実行可能です。（ただし画面遷移中・ロード中の連打割り込みは自動でガードされます）

---

## 🛠️ 使い方・ビルド手順

1. Visual Studio 2022 で `Mod_QuickSaveLoad.sln` を開きます。
2. ビルドを実行すると `config.bat` が走り、ゲーム側の依存アセンブリ参照の設定と BepInEx の `plugins` フォルダへの自動配置が行われます。
3. ゲームを起動し、自由行動画面などで **F5** / **F9** キーを押して動作を確認してください。

---

## 🔍 トラブルシューティング・確認方法

* **セーブされない／音が鳴らない**
* 会話中やバトル中など、セーブ不可の画面で F5 を押していないかご確認ください。


* **ログの確認**
* BepInEx のコンソール画面（または `BepInEx/LogOutput.log`）を開くと、`[QuickSave]` タグで「セーブ成功」「現在のシーン('Story')ではセーブできません」といった詳細なメッセージが出力されます。動作確認やデバッグにお役立てください。
