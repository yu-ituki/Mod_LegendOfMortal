# Mod_NewGamePlus

『活俠傳 (Legend of Mortal)』のロード画面から、過去のセーブデータのステータスや好感度を引き継いで「強くてニューゲーム」を開始できるModです。  

---

## 🎮 使い方

1. ゲームを起動して、ロード画面を開きます。
2. 引き継ぎ元にしたいセーブデータを選択します。
3. **`F1` キー**（設定で変更可能）を押して、引き継ぎメニューを開きます。
4. 引き継ぎたい項目（ステータス・好感度・門派資産）を選んで「開始」をクリック
5. 引き継ぎ状態でニューゲームが始まります  

※引き継ぎ元のセーブデータはそのまま残ります

---

## 📋 引き継ぎ項目

* **引き継げるもの**
  * 主人公の各種ステータス（体力、内力、学問、性格、武功の習熟度など）
  * 性格（人柄）: 性情、處世、修養、道德
  * キャラクターたちの好感度
  * 唐門の資産（選択した場合）
* **リセットされるもの**
  * 称号、恋愛関係（恋人フラグなど）
  * 所持アイテム、本、クエストの進行状況

---

## 🔧 設定 (Config)

`BepInEx/config/yu-ituki.mortal.mod-newgameplus.cfg` でキー割り当てを変更できます。

```ini
[Keybinds]
# ロード画面でNewGamePlusを開始するキー
NewGamePlusKey = F1
